Como funciona a run

Você começa com 3 vidas. Cada acerto avança um andar e rende 3 moedas; a cada 5 andares há uma sala do chefe, que paga 8.

Cada erro custa uma vida. Sem vidas, a run termina. Na run você vê a resposta certa depois de cada questão.

Cada run sorteia 3 cartas entre 9 possíveis. Gaste moedas nelas durante a questão: eliminar alternativas, pedir uma dica à IA, recuperar vida, entre outras.

O recorde de andares fica salvo neste navegador.

Como funciona a speedrun

Cada questão tem 4 minutos. A prova real dá 3min40s por questão (90 questões em 5h30), então 4 minutos é um limite folgado de treino.

Quanto mais rápido você acerta, mais pontos ganha: de 1000 (resposta imediata) a 100 (no limite dos 4 minutos).

A run acaba no primeiro erro ou quando o tempo de uma questão se esgota. Não há assistência de IA e o relógio só corre enquanto você está na questão.

A melhor pontuação fica salva neste navegador.
